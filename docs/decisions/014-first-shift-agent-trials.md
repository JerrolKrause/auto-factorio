# Decision 014: bounded First Shift agent trials

Phase 12 composes the existing coordinator, durable journal, character gateway, evaluator and dashboard. [Trial plan](../../apps/runtime/trial-plan.ts), [provider host](../../apps/runtime/gameplay-provider.ts), [MCP adapter](../../packages/tools/src/coordination-mcp.ts), and [launcher](../../scripts/scenario-trial.ts) keep provider protocol, gameplay authority and experiment policy separate.

The two declared runs are an unassisted team with one fresh engineer context and a separate assisted team. Defaults are 30 roster turns, 90 seconds and 20 attempted tools per turn, concurrency ceiling two, 30 game minutes, 45 wall minutes and 600,000 reported tokens per run. The current scheduler admits one role at a time and lets the game execute between turns. Token enforcement is approximate; unavailable telemetry is `null`, never inferred from turns. No automatic repeated trials seek a passing model result.

The operator supplies retained phase 11 evidence. Preflight requires the successful reference, bypass failures, identical source hashes and the same fixture fingerprint. Evidence remains operator-only. Public scenario facts and legal tool contracts enter gameplay contexts; reference layouts do not. Both roles pass managed ChatGPT authentication, Astra/low selection, environment isolation and exact MCP catalog checks before any inference. Per-process settings disable inherited tools without changing global settings. The integration continues using the pinned app-server interface described in [official documentation](https://learn.chatgpt.com/docs/app-server).

MCP credentials allow catalog discovery before a turn, but calls remain closed until the provider verifies the turn and the coordinator binds its identity. `build` fills epoch, control session, actor and fencing generations from acknowledged ownership; existing runtime validation and legal character execution still apply. Old credentials remain revoked. A new provider process is used each turn; ordinary continuation resumes only that role's thread. The replacement exercise starts a new thread while construction is pending, reads reconciled durable commands and requires a fresh authorized `replacement` observation. It retains the same budget. Missing exercise evidence is a gap, not a claimed pass.

The foreman requests one independent verification attempt. The deterministic host samples settling and scored windows while character mutation is closed in Lua. An operator hint enters the existing durable advice inbox with exact text and both clocks; the agent's interpretation and task links remain separate evidence. Reports distinguish the reference, software/integration status, model outcome and incomplete exercises. Unknown intervention causality remains unknown.

All trial game clients share a serialized command port; a transport failure closes its queue without retrying unknown effects. A dashboard pause retains the host, budgets and verification attempt. Resuming ordinary construction still replaces authority through the existing barrier. An admitted observation-only verification interval has a narrowly guarded same-authority resume: ordinary operator pause, neutral held world, no checkpoint, no suspended orders and an intact admitted baseline. Lua rejects restore/watchdog/invalidated cases, and the runtime keeps character admission closed. The live reference probe exercises pause, frozen polling and resume during its positive interval; changed guard bytes require fresh reference/control evidence before inference.

Live evidence and final implementation status belong in the [handoff](../IMPLEMENTATION_HANDOFF.md). Developer verification and independent review remain required; the existence of a report does not establish acceptance.

The first model-backed trial exposed watchdog expiry while processing accumulated receipts. Polling now renews the last acknowledged control fence before ledger work; stale authority still fails closed. Reconciliation retains changed receipts without repeating identical durable commits. Concurrent coordinator callers await the same pump, and control recovery joins cancellation reconciliation before entering the execution boundary. This preserves the existing watchdog deadline and does not retry unknown effects.

Provider cancellation callbacks only inspect acknowledged ownership; they never start a late competing pump. Real accumulated ledgers also exceeded the 64 KiB gameplay RPC limit during recovery. Only operator `reconcile` now permits up to 4 MiB of JSON; all other requests retain 64 KiB, and Lua still requires the exact held ledger and fresh authority. The reference probe verifies a ledger above the old limit through ordinary reconcile, re-arm, heartbeat and final hold.

The ordinary scheduler then releases that same intent. Clocks and budgets continue throughout the hold. Reports identify this as queued-work continuation; the v1 attempt whose batch finished during provider startup remains incomplete evidence.
